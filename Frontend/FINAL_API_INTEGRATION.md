## Complete User Flow

### 1. Registration & Login
```
1. User registers → POST /Auth/register
2. User logs in → POST /Auth/login
3. JWT token stored in localStorage
4. User data stored in AuthContext
```

### 2. Baby Profile Setup
```
1. BabyContext auto-fetches → GET /Baby
2. If no babies → Show "Create Baby Profile" prompt
3. User creates baby → POST /Baby
4. Baby auto-selected and stored
5. Baby ID used in all subsequent API calls
```

### 3. Dashboard
```
1. Loads with selected baby ID
2. Fetches mental health assessment
3. Fetches recent journal entries
4. Fetches mood trends
5. All data displayed in real-time
```

### 4. Journal Entry
```
1. User writes journal entry
2. Selects mood
3. Submits → POST /Journal/entries
4. API analyzes with AWS Comprehend
5. Returns sentiment scores
6. Detects red flags
7. Shows emergency resources if needed
8. Entry saved to database
```

### 5. Daily Advice
```
1. User clicks "Generate Daily Advice"
2. API call → POST /DailyAdvice/generate?babyId={id}
3. AWS Bedrock generates personalized advice
4. Based on baby's age (days old)
5. Considers recent journal entries
6. Returns AI-generated advice
7. Displays with category and metadata
```
